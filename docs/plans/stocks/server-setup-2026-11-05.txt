4. KITE RELAY on the server
---------------------------
- Code: /opt/mcube-src/mcube/relay (git clone of this repo)
- Env:  /etc/mcube/relay.env (chmod 600), holds
        KITE_API_KEY, KITE_RELAY_SECRET, PORT=3100
- Service: systemd unit mcube-kite-relay
    systemctl status|restart mcube-kite-relay
    journalctl -u mcube-kite-relay -f
- HTTPS: Caddy, /etc/caddy/Caddyfile
    relay.mcubetechstudio.com { reverse_proxy 127.0.0.1:3100 }
- Check: curl https://relay.mcubetechstudio.com/health
         -> {"ok":true,"version":2,"gtt":true}
- To update the relay code:
    cd /opt/mcube-src/mcube && git pull && systemctl restart mcube-kite-relay

7. DAILY PRICES (free): NSE bhavcopy -> stocks.daily_ohlcv
----------------------------------------------------------
- Script:  /opt/mcube-jobs/bhav.py
  Source: nsearchives.nseindia.com/products/content/sec_bhavdata_full_DDMMYYYY.csv
  Keeps SERIES=EQ rows and upserts ticker, date, open, high, low, close,
  volume on (ticker, date).
  Then recomputes rsi for the new rows.
- RSI formula: simple 14-day RSI (rolling mean of gains and losses).
  "bhav.py verify" matched the existing rsi values exactly on 99.7% of
  rows; Wilder RSI did not match.
- Wrapper: /opt/mcube-jobs/bhav.sh (uses the scanner's venv and .env,
  RSI_METHOD=simple)
- Cron:    30 19 * * 1-5 /opt/mcube-jobs/bhav.sh   (19:30 IST, weekdays)
- Log:     /var/log/mcube-bhav.log
- Backfill on 5 Nov: 118 trading days loaded (23 May -> 4 Nov 2026).
- Manual run from a given date:  /opt/mcube-jobs/bhav.sh 2026-11-01
- NSE holidays and not-yet-published days are logged as "no file" and skipped.
